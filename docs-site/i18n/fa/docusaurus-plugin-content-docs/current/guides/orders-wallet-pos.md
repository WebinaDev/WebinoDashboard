# سفارشات، کیف پول، C2C و صندوق

APIهای ادمین تحت `/api/v1` با گیت زیرماژول‌های `orders`، `c2c`، `wallet`، `pos`.

## سفارشات

لیست با فیلتر/آمار/بالک، ایجاد و ویرایش Composer، جزئیات (یادداشت، مرجوعی، پرینت). پنل‌های مارکت‌پلیس/تپین/مودیان فعلاً «به‌زودی».

مسیرهای ادمین: `/admin/orders`، `/new`، `/:id`، `/:id/edit`.

## کارت‌به‌کارت

تنظیمات + لیست رسیدهای pending و approve/reject → `/admin/orders/c2c-receipts`.

## کیف پول

تنظیمات، موجودی/ledger، adjust، topup ادمین، moderation برداشت‌ها. پورتال مشتری بعداً.

## صندوق

POS ساده، لینک پرداخت، سفارش‌های من. مسیرها: `/admin/pos`، `/pay-link`، `/my-orders`.
